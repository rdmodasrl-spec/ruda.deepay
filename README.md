# DEEPAY

DEEPAY 是独立数字钱包与支付平台项目，目标、第一阶段范围和长期工程标准见：

- [产品、架构与第一阶段验收规格](./docs/DEEPAY-PRODUCT-SPEC-V1.md)
- [永久工程与 UI 设计标准](./docs/DEEPAY-ENGINEERING-AND-UI-STANDARDS.md)

## 当前仓库基线

当前提交包含 DaxPay 管理端/前端静态资源。此工作区尚未核实 DaxPay 后端源码、数据库、API、运行环境或其版本；在开展产品功能开发前，应按规格文档完成一次有边界的源码现状检查。本文档中的功能与验收项是目标，不表示已经实现。

## 开发阶段边界

当前只规划第一阶段封闭式内部测试：内部账户、模拟法币和测试网络。不得接入公众真实资产或真实提现，不部署正式 RUD 主网合约。真实资产运营需等待所需法律、许可、托管、安全和运营条件完成。

## 钱包前端当前状态

根目录钱包页面是尚未连接钱包 API、认证、数据库或复式账本的前端原型。它不提供真实余额、充值地址、交易记录、二维码或资金提交；所有未接入的操作均应明确标示不可用。DaxPay 管理端和商户端保持独立，不能替代尚待开发的钱包账本服务。
